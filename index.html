The one number worth knowing

/close is 60% of every command run and 64% of every token SAGE spends on commands: 278 runs, ending 248 of your 276 chats, about 4 million tokens. It is mandatory by design and it is doing its job. How this was measured

Source: all 276 SAGE chat transcripts in this vault, September 11 to October 8, 2026. A run is a typed slash command or SAGE invoking the skill itself; both are counted. A run lasts until your next message. Minutes, tool calls and tokens are medians per run, so one long session cannot skew a command. Front-desk passes /va makes inside /start and /eod are counted under those commands, not under /va. Zero chat runs is not the same as zero use: a scheduled task, a button in ACE, or plain conversation can do the same work without the command. Counts only, no client names, per the front-desk privacy rule.
